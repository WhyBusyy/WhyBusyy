### 💼 경력사항

#### 🏢 주식회사 루멘테라 / Frontend & Backend Developer

**기간**: 2024.05 ~ 현재

**서비스**: 약국 직거래 통합관리 플랫폼, [플랫팜](https://platpharm.com)

> 약국과 제약사 간의 상품 주문, 결제, 장부관리까지 한 번에 처리할 수 있는 B2B 직거래 통합관리 플랫폼으로, 약국 유통 구조의 디지털 전환을 목표로 하는 서비스입니다.

**주요 업무 및 성과**:

- ✅ **서비스 초기 설계 및 프론트엔드 구조 설계** (2024년 하반기)
  - 다양한 벤더사 요구사항을 반영한 확장 가능한 프론트엔드 아키텍처 설계
  - Zustand(클라이언트) + TanStack Query(서버) 상태 관리 전략 수립
  - 공통 컴포넌트 라이브러리 및 코드 컨벤션 확립

- ✅ **프론트엔드 성능 최적화** (2025년 상반기)
  - Lighthouse 성능 점수 **13점 → 78점** 개선
  - 라우트 기반 코드 스플리팅으로 초기 번들 크기 60%+ 감소
  - CDN 폰트 → 로컬 임베디드 폰트 전환, lazyOnLoad 적용으로 TBT 개선

- ✅ **자체 CMS 구축** (2025년 하반기 ~ 2026년 상반기) — Fullstack 단독 개발
  - NestJS 기반 RESTful API 설계 및 구현
  - WYSIWYG 에디터 + 드래그앤드롭 UI로 비개발자 운영 환경 구축
  - AWS S3 연동 파일 업로드 시스템 및 이미지 최적화 파이프라인 구현
  - 콘텐츠 수정 관련 개발 요청 **80%+ 감소**

- ✅ **WYSIWYG 에디터 마이그레이션** (2026년 3월)
  - CKEditor → Tiptap(ProseMirror) 전환
  - 패키지 크기 **2.5GB → 3MB** (99.8% 감소)
  - 운영 배포 시간 **12분 → 6분** (약 50% 단축)
  - 독립 npm 패키지 [tiptap-editor-kit](https://www.npmjs.com/package/tiptap-editor-kit)으로 오픈소스 배포

- ✅ **웨비나 라이브 스트리밍 페이지 구현** (2026년 2월)
  - Naver Cloud Player 기반 라이브 스트리밍 및 사전예약/실시간 현황 기능 개발

- ✅ **백엔드 API 개발 및 수정** (2025년 상반기 ~ 현재)
  - 제한된 백엔드 리소스 환경에서 Node.js 기반 API 개발·수정 병행
